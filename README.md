# Homebrew Tap

Homebrew casks for apps by [@latteine1217](https://github.com/latteine1217).

```sh
brew install --cask latteine1217/tap/ripen
```

| Cask | App |
| :--- | :--- |
| `ripen` | [Ripen](https://github.com/latteine1217/ripen), a native macOS Pomodoro timer with a floating window and a notch island |

Ripen updates itself through **Check for Updates…**; `brew upgrade --cask ripen` also works.
